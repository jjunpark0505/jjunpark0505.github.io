플레이트 랩 브런치 최종 홈페이지

[실행]
1. 압축을 풉니다.
2. index.html 파일을 더블클릭합니다.
3. PC와 모바일 화면 크기에 맞춰 자동으로 표시됩니다.

[적용된 기능]
- 대표 음식 사진 자동 슬라이드
- 메뉴 사진 클릭 시 확대 보기
- 모바일 전용 빠른 메뉴
- 네이버 지도 연결
- 전화 연결
- 인스타그램 @plate_lab_brunch 연결
- PLATE LAB AT HOME Coming Soon 섹션
- 음식과 음료 메뉴 구분
- 가격 미표기

[현재 메뉴]
- 수제 리코타 샐러드
- 닭다리살 스테이크
- 해물 토마토 파스타
- 스파이시 슈림프 파스타
- 불고기 파니니
- 커피
- 오렌지 에이드
- 오미자 에이드

[추후 교체하면 좋은 항목]
- 닭다리살 스테이크 실제 사진
- 커피 실제 사진
- 정확한 영업시간
- 정확한 네이버 플레이스 가게 링크

[인터넷 공개]
폴더 전체를 Netlify Drop, GitHub Pages, Vercel 등에 업로드하면 공개할 수 있습니다.
도메인을 구매한 경우 해당 서비스에서 연결할 수 있습니다.
